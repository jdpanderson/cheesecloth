# Security

To report a security problem, open an
[issue](https://github.com/jdpanderson/cheesecloth/issues), or a
[pull request](https://github.com/jdpanderson/cheesecloth/pulls) with a fix.

Cheesecloth is a pre-release hobby project, with no security team and no
promised response time. For what it does and does not protect against, see
[trust](TRUST.md).
