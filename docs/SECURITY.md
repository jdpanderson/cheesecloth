# Security

To report a security problem, use
[private vulnerability reporting](https://github.com/jdpanderson/cheesecloth/security/advisories/new).
Only the maintainer can see the report until a fix is out. For other
problems, open an [issue](https://github.com/jdpanderson/cheesecloth/issues),
or a [pull request](https://github.com/jdpanderson/cheesecloth/pulls) with a
fix.

Cheesecloth is a hobby project, with no security team and no
promised response time. For what it does and does not protect against, see
[trust](TRUST.md).
